# Mihomo 全局覆写脚本

[English](./README.md) | 简体中文

一份适用于 **Clash Party** 和 **Clash Verge Rev** 的分流脚本。导入后，它会自动整理 DNS、代理组和分流规则，让国内网站直连，常见海外服务按组选择节点，广告域名默认拦截。

> 本项目适合已经拥有可用代理订阅、希望减少手动配置的用户。它不提供代理节点或订阅服务。

## 它能做什么

- 保留当前配置中已有的订阅和节点
- 自动按香港、台湾、日本、新加坡、美国等地区整理节点
- 为 OpenAI、Claude、Gemini、YouTube、Netflix、Telegram 等常见服务建立独立策略组
- 国内网站和局域网默认直连，未匹配的流量统一交给“漏网之鱼”处理
- 提供自动测速、故障转移、负载均衡和手动选择
- 使用 fake-IP DNS，并兼顾常见局域网、系统联网检测和登录场景
- 默认拦截规则集命中的广告域名，也可以在客户端中切换为放行

## 使用前准备

你需要：

- 已安装 Clash Party 或 Clash Verge Rev
- 一份可用的代理订阅
- 下载本项目中的 `mihomo-global-override.js`

覆写脚本会接管 DNS、代理组和分流规则。首次使用前，建议保留一份当前配置，方便随时恢复。

## 快速开始

### 1. 选择节点来源

打开 `mihomo-global-override.js`，在文件开头找到 `proxyProviders`。

如果节点已经由客户端中的订阅提供，推荐删除 `p1`、`p2` 两段示例，只保留空对象：

```js
const proxyProviders = {};
```

如果希望由脚本加载订阅，请把 `p1`、`p2` 中的示例 `url` 换成自己的订阅地址。不需要两个订阅时，可以删除多余的一段。

> 订阅地址相当于账号凭据，请勿截图、公开分享或提交到 GitHub。

### 2. 导入脚本

在客户端中打开全局覆写或全局扩展脚本功能，导入 `mihomo-global-override.js`，然后启用脚本并更新配置。

不同客户端版本的菜单名称可能略有不同。如果同时启用了其他会修改 DNS、代理组或规则的覆写，请先关闭它们，避免互相覆盖。

### 3. 选择代理模式

导入成功后，在客户端的代理页面找到“总模式”：

- 不想手动挑选：选择“自动选择”
- 希望节点不可用时自动切换：选择“故障转移”
- 希望固定地区：选择对应的地区节点组
- 希望完全手动控制：选择“全部节点”
- 临时不使用代理：选择 `DIRECT`

各服务默认有自己的策略组。例如，可以让 OpenAI 使用美国节点，同时让 YouTube 使用自动选择。

## 默认分流方式

规则按照从上到下的顺序匹配，主要逻辑如下：

1. 局域网和系统兼容流量直接连接
2. 广告域名进入“广告拦截”组
3. 常见应用进入各自的服务组
4. 国内域名和 IP 直接连接
5. 其余流量进入“漏网之鱼”组

“漏网之鱼”默认跟随“总模式”，也可以手动改为直连。

## 常见问题

### 提示“没有可用代理”

脚本没有找到任何节点。请确认以下至少一项成立：

- 客户端当前配置已经包含节点或订阅
- `proxyProviders` 中已经填写可用的订阅地址

### 地区节点组为空

脚本根据节点名称识别地区。如果订阅使用了非常规命名，节点可能被归入“其他节点”。你仍然可以在“全部节点”中手动选择。

### 远程规则加载失败

远程规则集需要联网下载。请先检查网络和客户端日志，再尝试更新配置。

### 导入后无法上网

先停用该覆写并恢复原配置，确认原订阅本身可以使用。随后检查订阅地址、客户端日志，以及本机是否有其他代理、DNS 或防火墙软件同时接管网络。

### 广告被误拦截

在代理组中找到“广告拦截”，将它从 `REJECT` 切换为 `DIRECT` 即可临时放行。

## 哪些设置会被修改

脚本会保留原配置中的 `proxies` 和 `proxy-providers`，并重新生成以下内容：

- DNS 与域名嗅探设置
- 代理组
- 远程规则集
- 分流规则
- 部分通用设置，例如规则模式、监听端口和 IPv6

因此，它不适合与另一份负责相同内容的全局覆写同时使用。

## 进阶自定义

普通使用不需要修改下面的内容。希望增加服务分组时，可以在 `SERVICE_DEFINITIONS` 中添加定义，再补充对应的规则集和分流规则。

例如：

```js
["MyService", ["总模式", "香港节点", "日本节点", "DIRECT"]]
```

随后在 `DOMAIN_RULESETS` 中登记对应的远程规则，再在 `rules` 中引用：

```js
"RULE-SET,myservice-domain,MyService"
```

代理组名称、规则集名称和 `RULE-SET` 引用需要保持一致。规则越靠前，优先级越高。

## 检查脚本

如果电脑已安装 Node.js，可以在脚本所在目录执行：

```powershell
node --check .\mihomo-global-override.js
```

这只能检查 JavaScript 语法。修改规则后，还需要确认代理组名称没有重复、每个 `RULE-SET` 都有对应的规则集，并保留最后的兜底规则。

- 使用本脚本前，请确保其用途符合你所在地的法律法规及相关服务条款
